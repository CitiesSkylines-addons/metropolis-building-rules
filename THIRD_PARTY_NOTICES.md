# Third-party references / Riferimenti di terzi

Build-time references from the user's local Cities: Skylines 1 installation: `ICities.dll`, `UnityEngine.dll`, `Assembly-CSharp.dll`, `ColossalManaged.dll`. The mod also compiles against locally installed `CitiesHarmony.dll`, `CitiesHarmony.Harmony.dll`, and `CitiesHarmony.API.dll`. These files are not copied into this repository or release. Their own terms govern those files; the user must install CitiesHarmony separately.

Riferimenti di compilazione dall'installazione locale di Cities: Skylines 1: `ICities.dll`, `UnityEngine.dll`, `Assembly-CSharp.dll`, `ColossalManaged.dll`. La mod usa anche i file installati localmente `CitiesHarmony.dll`, `CitiesHarmony.Harmony.dll` e `CitiesHarmony.API.dll`. Non sono copiati nel repository o nella release. Per tali file valgono le rispettive condizioni; l'utente deve installare CitiesHarmony separatamente.

The [Citystate Metropolis public descriptions](docs/CITYSTATE_COMPARISON.md) are linked for factual comparison only. No source code or art from that project is used / Le descrizioni pubbliche di Citystate Metropolis sono collegate solo per confronto. Non si usano codice o immagini di quel progetto.
