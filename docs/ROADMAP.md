# Roadmap / Piano di sviluppo

1. **Alpha 0.1:** preferred height and asset-name filter for new vanilla-style growables / preferenza di altezza e filtro nome per nuovi growable vanilla.
2. **Alpha 0.2:** persisted per-district rules and compatibility checks with theme mods / regole persistenti per distretto e prove di compatibilità.
3. **Alpha 0.3:** asset metadata and named architectural presets with explicit asset lists / metadati e modelli architettonici con elenchi espliciti.
4. **Later:** reversible building placement controls for existing assets; investigate modular visuals separately / controlli reversibili di posizionamento; ricerca distinta sulle immagini modulari.

Arbitrary floor-by-floor mixed use, editable mesh height, and non-rectangular growable footprints require separate feasibility evidence and are not part of these releases / Destinazioni d’uso per piano, altezza arbitraria della mesh e growable non rettangolari richiedono verifiche separate e non fanno parte di queste release.
